# AutoHostUpdate

Автоматическая синхронизация выбранных групп записей в системном файле
`hosts` с сетевым источником **GeoHideDNS**.

Скрипт обновляет только те именованные группы, которые вы уже добавили в свой
`hosts` локально, и не трогает остальное содержимое файла. Группа —
блок строк, начинающийся с `# ИмяГруппы` и разделённый от других пустыми
строками.

## Как это работает

При каждом запуске скрипт:

1. Скачивает файл `hosts` из сетевого источника
   [geohide.ru/eu/hosts](https://geohide.ru/eu/hosts) во временный каталог. Если сайт недоступен или отсутствует интернет-соединение, скрипт выводит соответствующее уведомление и завершает работу.
2. Сравнивает дату обновления в источнике (строка 2: `# Последнее обновление: ...`)
   с датой, записанной в вашем локальном `hosts`.
3. Если даты совпадают — обновление не требуется, работа завершается.
4. Если источник новее — делает резервную копию `hosts`, заменяет **целиком**
   каждую именованную группу, которая есть и у вас, и в источнике (заголовок
   `# Имя` + все записи группы), обновляет маркер даты и сбрасывает DNS-кеш.

Что остаётся нетронутым:

- группы, которые есть только в источнике, но не добавлены вами локально —
  вы сами решаете, какие держать;
- неназванные блоки (стандартный заголовок Windows, блоки Telegram/Discord/
  GitHub/Xiaomi и т.п.).
