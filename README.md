# AutoHostUpdate

Автоматическая синхронизация выбранных групп записей в системном файле
`hosts` с сетевым источником **GeoHideDNS**.

Скрипт обновляет только те именованные группы, которые вы уже добавили в свой
`hosts` локально, и не трогает остальное содержимое файла. Группа —
блок строк, начинающийся с `# ИмяГруппы` и разделённый от других пустыми
строками.

## Как это работает

При каждом запуске скрипт:

1. Скачивает актуальный `hosts`-файл из источника
   [GeoHideDNS](https://raw.githubusercontent.com/Internet-Helper/GeoHideDNS/refs/heads/main/hosts/hosts).
2. Сравнивает дату обновления в источнике (строка 2: `# Последнее обновление: ...`)
   с датой, записанной в вашем локальном `hosts`.
3. Если даты совпадают — обновление не требуется, работа завершается.
4. Если источник новее — делает резервную копию `hosts`, заменяет **целиком**
   каждую именованную группу, которая есть и у вас, и в источнике (заголовок
   `# Имя` + все записи группы), обновляет маркер даты и сбрасывает DNS-кеш.

Что остаётся нетронутым:

- группы, которые есть только в источнике, но не добавлены вами локально —
  вы сами решаете, какие держать;
- неназванные блоки (стандартный заголовок Windows, блоки Telegram/Discord/
  GitHub/Xiaomi и т.п.).

## Состав проекта

| Файл | Назначение |
|---|---|
| `AutoHostUpdate.ps1` | Основной скрипт обновления `hosts`. |
| `Install-AutoHostUpdate.ps1` | Создаёт задачу в Планировщике задач для автозапуска при входе в систему. |
| `Uninstall-AutoHostUpdate.ps1` | Удаляет эту задачу. |
| `AGENTS.md` | Техническая документация для разработки. |

## Требования

- Windows (PowerShell 5.1 и выше, достаточно `powershell.exe`).
- Запуск от имени администратора — изменение `hosts` и `ipconfig /flushdns`
  требуют прав администратора.
- Доступ в интернет к raw-файлу GeoHideDNS.

## Установка

1. Скопируйте все файлы проекта в удобную папку.
2. Запустите от имени администратора:

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File Install-AutoHostUpdate.ps1
   ```

   Будет создана задача `AutoHostUpdate`, которая запускает скрипт при каждом
   входе в систему скрыто (без окна) и с максимальными правами.

Параметры установки:

- `-ScriptPath <путь>` — задать путь к `AutoHostUpdate.ps1`, если он лежит не
  рядом с установщиком (по умолчанию берётся текущая папка).
- `-Uninstall` — удалить задачу установщиком без отдельного скрипта.

## Ручной запуск

Из папки проекта, от имени администратора:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File AutoHostUpdate.ps1
```

Ключ `-Quiet` подавляет модальное окно ошибок (полезно при ручном запуске из
консоли или по своему расписанию):

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File AutoHostUpdate.ps1 -Quiet
```

## Удаление

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File Uninstall-AutoHostUpdate.ps1
```

Скрипт найдёт задачу `AutoHostUpdate` в Планировщике и удалит её. Если задача
отсутствует, он просто сообщит об этом.

## Уведомления

При каждом завершении работы показывается уведомление-пузырь в области
уведомлений Windows (не зависит от `-Quiet` — работает всегда):

- **Hosts обновлён** — заменено N групп и указан путь к резервной копии;
- **Обновление не требуется** — hosts уже актуален;
- **Пропуск** — другой экземпляр уже выполняется;
- **Ошибка** — пузырь с текстом ошибки (без `-Quiet` дополнительно открывается
  окно с кнопкой «Открыть лог»).

## Логи и резервные копии

- Журнал работы: `%TEMP%\AutoHostUpdate.log` (дописывается, с метками времени).
- Резервные копии `hosts`: `%TEMP%\AutoHostUpdate_backups\hosts_<дата-время>.bak`
  создаются перед каждой перезаписью файла. При необходимости верните копию
  в `C:\Windows\System32\drivers\etc\hosts`.

## Как добавить свою группу

1. Откройте `hosts` от имени администратора.
2. Добавьте блок с заголовком `# ИмяГруппы` и нужными записями, например:

   ```
   # MyGroup
   1.1.1.1  example.com
   ```

3. Имя в `# ИмяГруппы` должно совпадать с именем блока в файле-источнике
   GeoHideDNS.
4. При следующем запуске AutoHostUpdate группа будет синхронизироваться
   полностью.

## Ограничения

- Скрипт не создаёт новые группы из источника — только обновляет те, что уже
  есть в локальном `hosts`.
- Если имя группы совпадает по заголовку, но содержимое изменилось — группа
  будет заменена целиком.
